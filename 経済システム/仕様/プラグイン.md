# 統合経済プラグイン「FJ Economy」仕様書 (v1.0)
## 1. プロジェクト概要
マインクラフトJava版（Paper）を対象とした、完全独自設計の経済システム。既存のVault等に依存せず、Proxmox上の複数サーバー間で所持金をリアルタイム同期し、Web経由での分析・管理を可能にする。
### ネットワーク構成
 * **Database:** 10.2.1.27 (MariaDB: fjeconomy)
 * **Game Server 1:** 10.2.1.28 (Main / Proxmox CT)
 * **Game Server 2 & 3:** 10.2.0.10 (Sub / External PC)
 * **Web Dashboard:** 10.2.1.5 (Web-1 / clusters-prj.com)
## 2. コア仕様：通貨と同期
 * **単位:** 整数（INT）管理。1円単位で扱い、浮動小数点誤差を排除。
 * **リアルタイム同期:** どのサーバーで残高が変わっても、中央DBを介して全サーバーへ即座に反映。
 * **メインコマンド:** /fj
   * /fj bal : 所持金確認
   * /fj pay [player] [amount] : プレイヤー間送金
   * /fj admin [give|take|set] : 管理者用通貨操作
## 3. ショップシステム（モブショップ）
 * **店員NPC:** 特定のモブ（村人、Interaction等）をショップとして運用。
 * **店主（オーナー）概念:** 各NPCにプレイヤーUUIDを紐付け、売上をその店主の口座へ送金。
 * **在庫管理:** 中央DBで在庫数を管理。
## 4. 経済・税政システム
 * **政府口座 (GOVERNMENT):** システム全体の「国庫」。UUIDを固定し、税金や手数料をここに集約。
 * **自動課税:** 商品売買時に設定された税率（%）で徴収。
 * **端数処理:** 税金計算で発生した1円未満の端数は、**プログラム側で四捨五入**して整数化し、政府または店主に分配する。
 * **整合性ルール:** 販売価格 = 政府受取額(税) + 店主受取額(利益) を常に維持する。
## 5. Web連携（ダッシュボード）
clusters-prj.com を通じて以下の機能をWebから提供する。
| 権限 | 主な表示項目 |
|---|---|
| **店主** | 自分の店の売上履歴、商品別売上グラフ、在庫アラート |
| **政府** | 通貨発行量（全プレイヤー合計＋国庫）、税収推移、経済成長分析 |
| **一般** | 長者番付（ランキング）、サーバー全体の経済統計 |
## 6. データベース構造（確定版）
 1. **fje_balances**: プレイヤー残高（主キー: uuid）
 2. **fje_shops**: NPCショップ設定（主キー: npc_id, server_id）
 3. **fje_transactions**: 取引レシート（主キー: id）
 4. **fje_government_ledger**: 政府収支台帳（主キー: id）
   * ※全テーブルにおいて、金額に関連する列は原則 **INT**。
## 7. 開発・運用ポリシー
 * **非同期処理:** DBへの読み書きはすべて非同期で行い、ゲームサーバーのメインスレッドを止めない。
 * **セキュリティ:** Web画面へのアクセスは Cloudflare Tunnel ＋ Zero Trust で保護。
 * **障害対策:** DB（10.2.1.27）切断時は、残高の書き換えを一切禁止するロック機構を搭載。
